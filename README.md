# Flash Catalog

Android-приложение для каталога флешек, microSD и USB-накопителей.
Фото накопителя (с рамкой-направляющей) + аннотация сохраняются в папку, которую синхронизирует Syncthing.

Структура каталога:

```
<папка каталога>/
  .nomedia
  Storage-2026-10-01_12-30-00/
    .nomedia
    photo.jpg
    info.txt      <- аннотация обычным текстом
```

Сборка: GitHub Actions, готовый APK появляется в разделе Releases.
