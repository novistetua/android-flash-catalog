# Flash Catalog

Android-приложение для каталога флешек, microSD-карт, USB-накопителей и SSD. Снимаешь накопитель, приложение само вырезает фон и выравнивает кадр, ты пишешь пару строк про содержимое. В итоге получается каталог, в котором легко найти «ту самую флешку с Kali Linux». Каталог лежит обычными файлами в обычной папке, поэтому его синхронизирует Syncthing, а с другого устройства (телефон, ТВ-приставка, компьютер) его можно получить по QR, по ссылке или одним HTML-файлом.

Скачать готовое приложение: [Releases](../../releases/latest), файл `FlashCatalog-X.X.apk`. Номер версии виден в самом низу «Настроек» и в имени файла.

## Возможности

### Съёмка
- Своя камера на CameraX/Camera2 с рамкой-направляющей. Накопитель в кадре стоит по центру, снимок режется по рамке.
- **Макро-линза.** Приложение умеет открыть отдельный макро-объектив (проверено на Xiaomi Redmi Note 14 Pro), которого нет в списке обычных камер. Есть переключение «макро / основная», кнопки увеличения (значение запоминается), фонарик и ручной фокус с автоподбором («Найти фокус»).
- **Тип рамки** (меню сверху справа): microSD / SD, USB-флешка стоймя, SSD / диск (1.43 : 1) и **свободная рамка**. Свободную рамку тянут за углы и стороны, двигают за середину; размер запоминается. Это для накопителей любой формы.
- **Резкость** (кнопка внизу справа): выкл, мягкая, средняя, сильная. Усиливает мелкие детали и надписи («резкость») и локальный контраст крупных форм («чёткость»).
- Приложение делает серию кадров и оставляет самый резкий. Индикатор резкости в реальном времени подсказывает, когда фокус пойман.
- **Автокадр.** Приложение само находит накопитель на однотонном фоне и режет по его границам. Если границ не видно (светлая флешка на светлом фоне, глянцевая поверхность), оно честно об этом говорит и предлагает рамку, ИИ или ручное стирание.
- Снимок можно взять из галереи, а в приложение можно «поделиться» картинкой из любого другого приложения.

### Вырезание фона
- **Классика без ИИ**, прямо на телефоне: сегментация в цветовом пространстве Lab, водораздел с маркерами, восстановление выпуклой формы, проверка уверенности результата.
- **ИИ онлайн** по желанию: публичные сервисы Hugging Face (без регистрации; лимит на аккаунт), свой Space или свой сервер на компьютере, а также remove.bg. Порядок сервисов и токены задаются в «Настройках». В «Настройках» есть инструкция, как поднять свой ИИ-сервер на Windows.
- **Кисть.** Ручная доработка маски: ластик, увеличение щипком, отмена, диаметр ластика, порог, яркость и «край фона». Кисть можно применить поверх автоматического результата и поверх ИИ.
- Результат сохраняется как прозрачный PNG вместе со скрытым оригиналом и маской, поэтому правку можно продолжить позже или вернуть оригинал.

### Карточка
- Одна карточка = одна папка. Название, описание, главное фото и сколько угодно дополнительных (листаются вбок; для них доступны поворот, обрезка и яркость).
- Высота окна фото подстраивается под пропорции накопителя, а список компактный: больше карточек на экране.
- Поиск по названию и описанию.

### Сортировка
В «Настройках»: по алфавиту, по дате создания, по дате изменения (для дат и алфавита есть обратный порядок) и **ручной**. Карточки переставляются долгим нажатием и перетаскиванием, при этом включается ручной режим. Ручной порядок хранится отдельно и возвращается, если переключиться на другой вид и обратно. Тот же порядок используется в HTML-странице и в веб-ссылке.

### Обмен между устройствами
Всё работает без аккаунтов. Данные при передаче упаковываются в zip.

| Способ | Когда использовать | Шифрование |
|---|---|---|
| **QR, одна сеть** | Оба устройства в одном Wi‑Fi (или ZeroTier). Отправитель показывает QR, получатель сканирует. | AES-256-GCM, ключ только в QR |
| **QR через интернет** | Устройства в разных сетях. Зашифрованный файл временно кладётся на анонимный файлообменник, QR несёт ссылку и ключ. | AES-256-GCM, ключ только в QR |
| **Код (Magic Wormhole)** | Разные сети, без файлообменников. Код вида `7-слово-слово`. Совместим с `wormhole receive` на компьютере. | сквозное, встроено в протокол |
| **Обратный обмен** («Принять: показать QR») | У получателя нет камеры (ТВ-приставка) или это компьютер: получатель показывает QR, отправитель сканирует и шлёт. Тот же адрес открывается в браузере как страница загрузки. | нет (только локальная сеть, защита ключом в адресе) |
| **Ссылка для браузера** | Просмотр и скачивание в браузере без приложения. Показываются все адреса устройства (Wi‑Fi, ZeroTier, VPN). На странице есть кнопка «Скачать приложение» (APK прямо с телефона, без интернета и GitHub) и кнопка отправки карточек обратно. | нет (только локальная сеть; можно включить секретный ключ в ссылке) |
| **HTML-файл** | Одна страница со всеми фото и текстами, открывается где угодно офлайн: поиск, просмотр, тёмная тема. | нет |
| **Короткая ссылка через интернет** | Ввести адрес вручную на любом устройстве. | нет |
| **Отправить приложение** | Передать сам APK другому телефону по Wi‑Fi или файлом. Имя файла содержит версию. | нет |

Если QR включает веб-ссылку и его сканирует обычное приложение камеры, а Flash Catalog не установлен, откроется страница со ссылкой на скачивание приложения.

### Страница-редактор для компьютера
Один HTML-файл («Страница-редактор для компьютера» в обмене или `editor.html` в веб-ссылке). Открой его с диска в Chrome, Edge или Opera на Windows, Linux или macOS и выбери папку каталога (например, синхронизируемую Syncthing). Доступ к папке запоминается между запусками.
- просмотр, поиск, листание фото;
- правка описания, замена и поворот главного фото, добавление, поворот и удаление дополнительных фото;
- создание и удаление карточек;
- **«Отправить на телефон»**: вставь адрес с экрана «Принять» на телефоне (или наведи камеру на его QR) и отправь изменённые карточки по Wi‑Fi или ZeroTier. Syncthing для этого не нужен.

Ограничения: вырезание фона и переименование карточки в браузере недоступны; Firefox и Safari не умеют открывать папки.

### Запуск на Android TV
Приложение запускается на приставках и телевизорах (есть значок для лаунчера Leanback). Приставка принимает карточки через «Принять: показать QR». Учти, что на части приставок нет системного окна выбора папки.

## Каталог на диске

```
<папка каталога>/
  .nomedia
  Storage-2026-10-01_12-30-00/        <- имя папки = имя карточки
    .nomedia
    photo.jpg                          <- главное фото
    info.txt                           <- описание обычным текстом
    photo_nobg.png                     <- то же фото с прозрачным фоном (если вырезан)
    additionally-1.jpg, -2.jpg …       <- дополнительные фото
    .photo.jpg, .mask.png              <- скрытые: оригинал и маска для дальнейшей правки
```

Никаких баз данных: можно копировать, архивировать и править руками. Файл `.nomedia` скрывает фото каталога от галереи.

## Первый запуск
1. Скачай APK из [Releases](../../releases/latest), открой и разреши установку из неизвестных источников. Новая версия ставится поверх старой, потому что все сборки подписаны одним ключом, каталог при этом не затрагивается.
2. В «Настройках» выбери папку каталога (можно создать новую, например `FlashCatalog`). Если используешь Syncthing, выбирай ту папку, которую он синхронизирует.
3. «Добавить флешку»: сними накопитель, при необходимости поправь фон кистью, напиши описание и сохрани.

## Что уходит в сеть
- Без твоего действия приложение ничего не отправляет.
- **ИИ-вырезание** отправляет фото выбранному сервису (Hugging Face или remove.bg). Токены хранятся только на телефоне.
- **Обмен через интернет** загружает зашифрованный файл на анонимный файлообменник (ключа у них нет) или использует публичный сервер Magic Wormhole.
- **Локальные ссылки и приём** работают по HTTP внутри твоей сети без шифрования. Пользуйся ими в доверенных сетях.
- Провайдеры иногда блокируют файлообменники; тогда помогает VPN или обмен по коду.

## Сборка
Сборка идёт в GitHub Actions: Gradle (Kotlin 1.9, AGP 8.5, minSdk 24, targetSdk 34), клиент Magic Wormhole для arm64 собирается из исходников и кладётся в приложение как нативная библиотека. Каждая сборка публикуется как релиз `build-N` с файлом `FlashCatalog-X.X.apk`; версия получается из номера сборки (сборка 58 = версия 5.8). Подпись фиксированная (`flashcatalog.keystore`), чтобы обновления ставились поверх.

Локально: `gradle assembleRelease -PbuildNumber=58`.
